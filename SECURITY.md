# Security Policy

## Supported development line

Security fixes are applied to `main`, which is the only active development
line.

## Reporting

Please report security-sensitive issues through this repository's GitHub
Security Advisory flow rather than a public issue.

Useful reports include:

- affected commit/version,
- reproduction steps,
- expected vs actual behavior,
- impact,
- minimal logs or proof-of-concept information.

Do not include ROMs, extracted proprietary assets, credentials, or unrelated
private data in a report.

## Scope

Security reports are appropriate for issues such as:

- memory corruption introduced by host-port changes,
- unsafe file/archive handling,
- command execution in tooling,
- CI or packaging vulnerabilities,
- dependency/supply-chain concerns.

Ordinary game bugs, rendering defects, and compatibility regressions should use
the normal issue tracker.
