# Security and private-data reporting

For ordinary bugs, use GitHub Issues.

Do not publish credentials, access tokens, private keys, ROM files, copyrighted extracted game data, or personal information in an issue, log or pull request.

If a log contains local usernames, home-directory paths, network details or other information you do not want public, redact those fields before posting it.

For a security-sensitive defect, contact the maintainers privately before publishing exploit details.
