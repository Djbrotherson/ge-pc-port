# Attribution and notices

This repository contains substantial new work for:

- the R36S / PortMaster AArch64 target,
- GLES-oriented host support,
- LP64/N64 semantic fixes,
- binary-layout and sidecar conversion contracts,
- semantic auditing and reusable N64 port tooling,
- target verification and packaging workflows.

That work is built on earlier open-source projects rather than being a
from-scratch reimplementation.

## Upstream foundations

The repository is derived from the GoldenEye 007 decompilation and an existing
GoldenEye PC-port codebase. Some host-port architecture and compatibility work
also follows patterns established by other N64 source ports.

Existing upstream copyright notices and license terms remain applicable to
the code those projects authored.

The repository's existing MIT license text is preserved in `LICENSE`.
